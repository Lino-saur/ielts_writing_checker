单线图写作思路：
先时间后最值原则 -- 从古到今
2. 找点：
找点：起点，终点，特征点（拐点，最值点）
1）变化总趋势 （起点和终点）
2）变化的阶段性趋势 (拐点 （前后趋势相反）+ 最值 + 阶段值（变化幅度有明显差异））
3. 连线：
*时间顺序连线：趋势（上升，下降，不变，波动）
